# Security Policy

This repository is a fork of [openRin/Rin](https://github.com/openRin/Rin).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/openRin/Rin/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
